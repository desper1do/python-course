**Цель урока.** После урока ты умеешь:

- хранить числа в списке, брать элементы по индексу и срезом;
- считать `sum`, `min`, `max`, `len` для списка;
- читать числа из строки через `split` и работать с множествами.

**Связь с МЦКО.** Для заданий 13 (файл с числами), 5 и 6 нужно хранить и перебирать наборы значений.

## 1. Список

**Список** — упорядоченный набор значений в квадратных скобках. Индексы и срезы работают как у строк.

```python
marks = [5, 4, 3, 5]
print(marks[0])
print(marks[-1])
print(marks[1:3])
print(len(marks))
```

## 2. append и перебор

`append` добавляет элемент в конец. Список можно перебирать циклом.

```python
n = int(input())
numbers = []
for i in range(n):
    numbers.append(int(input()))
for x in numbers:
    print(x * 2)
```

Начинаем с пустого списка `[]`, как с `total = 0` для суммы.

## 3. sum, min, max, sorted

```python
numbers = [4, 9, 2]
print(sum(numbers))
print(min(numbers))
print(max(numbers))
print(sorted(numbers))
```

Что выведут последние четыре строки?

<details>
<summary>Показать ответ</summary>

`15`, `2`, `9` и `[2, 4, 9]`. Функция `sorted` возвращает новый список по возрастанию.

</details>

## 4. Числа в одной строке: split

`input().split()` режет строку по пробелам и возвращает список **строк**. Числа нужно превратить через `int`.

```python
numbers = []
for word in input().split():
    numbers.append(int(word))
print(numbers)
```

Если ввести `3 8 1`, выведется `[3, 8, 1]`.

> 💡 Чтобы вывести числа через пробел: собери список строк и склей `" ".join(items)`. Если нужен просто столбец, выводи в цикле `print(x)`.

## 5. Множества

**Множество** хранит каждое значение один раз, порядок не важен.

```python
a = set()
for x in [3, 1, 3, 2, 1]:
    a.add(x)
print(len(a))
print(3 in a)
b = {2, 3, 7}
print(a & b)
```

`add` добавляет элемент, `in` проверяет, `&` — пересечение (общие элементы). Выведется `3`, `True`, `{2, 3}`.

## Типичные ошибки

> ⚠️ `IndexError: list index out of range` — индекс больше последнего. Для списка из 4 элементов последний индекс 3.

> ⚠️ `TypeError: unsupported operand type(s) for +: 'int' and 'str'` — в список попали строки (забыла `int`), а потом `sum`.

> ⚠️ `AttributeError: 'list' object has no attribute 'add'` — `add` у множества, у списка `append`.

## Итоги

- Список: `[]`, индексы с 0, `append`, срезы.
- `sum`, `min`, `max`, `len`, `sorted` работают со списками.
- `input().split()` даёт список строк, числа получаем через `int`.
- Множество хранит только уникальные значения; `&` — общие элементы.
