**Цель урока.** После урока ты умеешь:

- склеивать строки через `+` и повторять через `*`;
- считать длину строки через `len` и собирать текст с числами через f-строку;
- переводить между строкой и числом (`str`, `int`) и сравнивать строки.

**Связь с МЦКО.** Прямых заданий нет. Строки понадобятся в заданиях 6 (слова из букв) и 9 (длина серийного номера).

## 1. Склейка и повтор

`+` склеивает строки, `*` повторяет строку нужное число раз. Что выведет программа?

```python
print("Привет, " + "Аня")
print("ха" * 3)
print("-" * 20)
```

<details>
<summary>Показать ответ</summary>

`Привет, Аня`, затем `хахаха`, затем двадцать дефисов подряд.

</details>

> 💡 Запятая в `print` ставит пробел сама, а `+` ничего не добавляет: пробелы пиши в кавычках.

## 2. Длина строки

`len(text)` возвращает число символов. Пробелы тоже считаются.

```python
word = input()
print(len(word))
```

Для `Привет` будет `6`, для `a b` будет `3`.

## 3. f-строки

Перед кавычкой пишем букву `f`, а в фигурных скобках `{ }` подставляем переменные и даже вычисления.

```python
name = input()
age = int(input())
print(f"Меня зовут {name}, мне {age} лет.")
print(f"Через год мне будет {age + 1}.")
```

## 4. Строка и число

Склеить строку с числом нельзя, нужно превратить число в строку: `str(15)` даёт `"15"`. Обратно: `int("15")` даёт число `15`.

```python
a = 12
b = 34
print(str(a) + str(b))
print(int(str(a) + str(b)) * 2)
```

Первая строка выведет `1234` (склеились две строки), вторая `2468`.

## 5. Сравнение строк

Операторы `==`, `<`, `>` сравнивают и строки. Результат — `True` («истина») или `False` («ложь»). Сравнение идёт по буквам слева направо, как в словаре.

```python
print("абрикос" < "банан")
print("кот" == "кит")
print(max("кот", "кит"))
```

Функция `max` выбирает большее из значений, а для строк — то, что дальше по алфавиту. Предскажи вывод до запуска.

<details>
<summary>Показать ответ</summary>

`True`, `False` и `кот` (буква `о` стоит дальше, чем `и`).

</details>

> ⚠️ Заглавные буквы «меньше» строчных: `"Яблоко" < "арбуз"` истинно. А `"10" < "9"` тоже истинно: сравниваются первые символы `1` и `9`, как буквы.

## Типичные ошибки

> ⚠️ `TypeError: can only concatenate str (not "int") to str` — склеила текст с числом. Пиши `"Мне " + str(15)` или f-строку.

> ⚠️ `TypeError: can't multiply sequence by non-int of type 'str'` — умножаешь строку на строку. Число из `input()` сначала переведи через `int()`.

> ⚠️ `SyntaxError: f-string: expecting '}'` — потеряла закрывающую скобку `}` в f-строке.

## Итоги

- `+` склеивает строки, `*` повторяет.
- `len(s)` — число символов, пробелы тоже.
- f-строка: `f"Мне {age} лет"`.
- `str()` и `int()` переводят между строкой и числом.
- Строки сравниваются по буквам слева направо.
