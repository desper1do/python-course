## 1. Команды

Черепаха стартует в точке `(0, 0)` и смотрит вверх (на «север»). Команды:

| команда | что делает |
|---|---|
| `Вперёд n` | идёт вперёд на `n` клеток |
| `Назад n` | идёт назад на `n` клеток |
| `Направо a`, `Налево a` | поворачивает на `a` градусов (мы берём 90, 180, 270) |
| `Поднять хвост`, `Опустить хвост` | перестаёт или начинает рисовать |
| `Повтори k [ ... ]` | выполняет команды в скобках `k` раз |

Вверх — это `+y`, вправо — `+x`. Направление в градусах: `0` — вверх, `90` — вправо, `180` — вниз, `270` — влево.

## 2. Трассировка

Программа: `Вперёд 3 Направо 90 Вперёд 2`.

| шаг | команда | позиция | направление |
|---|---|---|---|
| 0 | | (0, 0) | 0 |
| 1 | Вперёд 3 | (0, 3) | 0 |
| 2 | Направо 90 | (0, 3) | 90 |
| 3 | Вперёд 2 | (2, 3) | 90 |

Повороты считаем остатком от деления на 360:

```python
angle = 0
angle = (angle + 90) % 360
angle = (angle - 180) % 360
print(angle)
```

Выведется `270`. Где окажется Черепаха после `Повтори 4 [ Вперёд 2 Направо 90 ]`?

<details>
<summary>Показать ответ</summary>

В точке `(0, 0)` и будет смотреть вверх: нарисован квадрат 2 на 2, четыре поворота по 90 градусов дают полный круг.

</details>

## 3. Как это сделать в Python

Позицию меняем по направлению: для угла `angle` смещение берём из списков.

```python
dx = [0, 1, 0, -1]
dy = [1, 0, -1, 0]
x = 0
y = 0
angle = 90
x += dx[angle // 90] * 3
y += dy[angle // 90] * 3
print(x, y)
```

Выведется `3 0`: направление 90 — вправо, на 3 клетки. Поворот: `angle = (angle + 90) % 360`.

## 4. Фигуры и целые точки

Если фигура — прямоугольник с границами `x1 < x < x2` и `y1 < y < y2`, то внутри (без границы) целых точек `(x2 - x1 - 1) * (y2 - y1 - 1)`. Для пересечения двух прямоугольников берём `max` левых границ и `min` правых; если получилось число не больше нуля, пересечения нет.

```python
left = max(0, 2)
right = min(5, 4)
print(right - left - 1)
```

> 🎯 МЦКО: «внутри» значит строго внутри, точки на границе не считаются.

Для сложных фигур проще перебрать точки по сетке и проверять условие.

## Типичные ошибки

> ⚠️ `IndexError: list index out of range` — угол не приведён к диапазону 0–359: забыла `% 360`.

> ⚠️ Посчитала точки на границе. Внутри — строго между границами, поэтому `- 1`.

> ⚠️ Забыла, что `Налево` уменьшает угол, а `Направо` увеличивает.

## Итоги

- Старт `(0, 0)`, направление 0 — вверх; `Направо` прибавляет угол.
- Смещение по списку `dx`, `dy` с индексом `angle // 90`.
- Внутри прямоугольника целых точек `(ширина - 1) * (высота - 1)`.
- Пересечение: `max` левых и `min` правых границ.
