**Цель урока.** После урока ты умеешь:

- читать последовательность чисел в список;
- перебирать пары соседних элементов `a[i]` и `a[i + 1]`;
- искать `N` по условию и считать количество и максимум по парам.

> 🎯 МЦКО: задание 13 — файл с числами, найти N (например, наименьшее число, не кратное 15), посчитать пары по условию и найти максимальную сумму. Ответ — два числа.

> 💡 Сейчас числа приходят с клавиатуры: первая строка — сколько чисел, дальше сами числа. На МЦКО они лежат в файле. Разница только в чтении, остальное решение то же.

## 1. Читаем последовательность

```python
n = int(input())
numbers = []
for i in range(n):
    numbers.append(int(input()))
print(numbers)
```

Для файла схема такая (запустить это здесь пока нельзя, поэтому это пример текста):

```text
with open("13.txt") as f:
    numbers = []
    for word in f.read().split():
        numbers.append(int(word))
```

Метод `read()` читает весь файл целиком, `split()` режет его на числа.

## 2. Соседние пары

Пара — это `numbers[i]` и `numbers[i + 1]`. Последняя пара начинается с индекса `len(numbers) - 2`, поэтому цикл идёт до `len(numbers) - 1`.

```python
numbers = [3, 5, 8, 2]
for i in range(len(numbers) - 1):
    print(numbers[i], numbers[i + 1])
```

Какие пары выведутся?

<details>
<summary>Показать ответ</summary>

`3 5`, `5 8` и `8 2`. Всего пар на единицу меньше, чем чисел.

</details>

## 3. Типичный план задания 13

1. Прочитать числа в список.
2. Найти `N`: например, наименьшее число, которое не делится на 15.
3. Перебрать пары соседних и отобрать подходящие (по кратности, сумме, порядку).
4. Посчитать количество и максимум.

```python
numbers = [14, 30, 7, 45, 16]
best = 0
count = 0
for i in range(len(numbers) - 1):
    s = numbers[i] + numbers[i + 1]
    if s % 3 == 0:
        count += 1
        if s > best:
            best = s
print(count, best)
```

Максимум можно начать с 0, только если все суммы положительны.

> ⚠️ Если пар по условию может не быть, максимум придётся хранить иначе (проверять `count == 0`).

## Типичные ошибки

> ⚠️ `IndexError: list index out of range` — цикл дошёл до последнего индекса, а ты обращаешься к `numbers[i + 1]`. Цикл должен идти до `len(numbers) - 1`.

> ⚠️ `ValueError: invalid literal for int() with base 10: ''` — читаешь больше чисел, чем во вводе.

> ⚠️ Искала `N` среди всех чисел, а нужно только среди тех, что не кратны 15. Условие в `if`.
