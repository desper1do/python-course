**Цель урока.** После урока ты умеешь:

- применять `+ - * / // % **` и знаешь порядок действий;
- находить целую часть и остаток от деления;
- доставать цифры числа через `//` и `%`.

**Связь с МЦКО.** Остатки и цифры нужны в заданиях 8, 11 и 13 (кратность, модульная арифметика). Сейчас просто учимся их считать.

## 1. Операции

| знак | что делает | пример | результат |
|---|---|---|---|
| `+` `-` `*` | сложить, вычесть, умножить | `4 * 5` | `20` |
| `/` | обычное деление, всегда дробное | `7 / 2` | `3.5` |
| `//` | целая часть деления | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | степень | `2 ** 3` | `8` |

Что выведут три строки? Предскажи, потом запусти.

```python
print(17 / 5)
print(17 // 5)
print(17 % 5)
```

<details>
<summary>Показать ответ</summary>

`3.4`, `3` и `2`. В 17 пять помещается 3 раза целиком, и остаётся 2.

</details>

## 2. Порядок действий

Как в математике: сначала `**`, затем `*  /  //  %`, потом `+  -`. Скобки главнее всего.

```python
print(2 + 3 * 2 ** 2)
print((2 + 3) * 2 ** 2)
```

Первая строка даёт `14` (степень, потом умножение, потом сложение), вторая `20`.

## 3. Целая часть и остаток

17 яблок раскладываем по коробкам по 5 штук: `17 // 5 = 3` полных коробки, `17 % 5 = 2` яблока остаётся. Так же устроены часы: в 130 минутах `130 // 60 = 2` часа и `130 % 60 = 10` минут.

```python
minutes = int(input())
print(minutes // 60, "ч", minutes % 60, "мин")
```

> 💡 Остаток от деления на 2 показывает чётность: `n % 2` равно `0` у чётных чисел и `1` у нечётных. Если остаток от деления на `k` равен 0, число делится на `k` нацело.

## 4. Цифры числа

Возьмём `n = 482`:

- `n % 10` даёт `2` — последняя цифра;
- `n // 10` даёт `48` — число без последней цифры;
- `n // 10 % 10` даёт `8` — вторая цифра с конца;
- `n // 100` даёт `4` — первая цифра трёхзначного числа.

```python
n = int(input())
print(n % 10)
print(n // 10 % 10)
print(n // 100)
```

## Типичные ошибки

> ⚠️ `ZeroDivisionError: division by zero` — делишь на ноль. Проверь, что стоит справа от `/`, `//` или `%`.

> ⚠️ `TypeError: 'int' object is not callable` — между числом и скобкой пропущен знак. Пиши `2 * (3 + 4)`, а не `2(3 + 4)`.

> ⚠️ `print(10 / 4)` выводит `2.5`, а не `2`. Если нужна целая часть, пиши `//`.

## Итоги

- `//` — целая часть, `%` — остаток, `/` — деление с дробью.
- Порядок: `**`, потом `* / // %`, потом `+ -`, скобки главнее всего.
- `n % 10` — последняя цифра, `n // 10` — число без неё.
- Остаток 0 значит «делится нацело».
