**Цель урока.** После урока ты умеешь:

- переводить число в десятичную систему по весам разрядов;
- переводить десятичное число в другую систему делением с остатком;
- пользоваться `bin()`, `hex()` и `int(строка, основание)`.

> 🎯 МЦКО: задания 3 и 11 (системы счисления), основа — перевод туда и обратно.

## 1. Позиционная запись

В десятичной системе цифра зависит от места: `472 = 4*100 + 7*10 + 2`. В системе по основанию `b` вес разряда — степень `b`. Основание пишем маленьким числом справа внизу: `1011₂` читаем «1011 в двоичной».

`1011₂ = 1*8 + 0*4 + 1*2 + 1*1 = 11`.

Веса для двоичной: 1, 2, 4, 8, 16, 32, 64, 128. Цифры больше 9 обозначают буквами: `A = 10`, `B = 11`, …, `F = 15`.

## 2. Из десятичной в другую: деление с остатком

Делим число на основание, записываем остатки, пока не получим 0. Читаем остатки снизу вверх.

Переведём `13` в двоичную: `13 // 2 = 6` (остаток 1), `6 // 2 = 3` (остаток 0), `3 // 2 = 1` (остаток 1), `1 // 2 = 0` (остаток 1). Снизу вверх: `1101₂`.

## 3. Python-помощники

```python
n = 13
print(bin(n))
print(hex(255))
print(int("1101", 2))
print(int("FF", 16))
```

Что выведет программа?

<details>
<summary>Показать ответ</summary>

`0b1101`, `0xff`, `13` и `255`. Префиксы `0b` и `0x` — пометки системы, их можно отрезать срезом: `bin(n)[2:]`.

</details>

## 4. Перевод своими руками

```python
digits = "0123456789ABCDEF"
n = int(input())
base = int(input())
result = ""
while n > 0:
    result = digits[n % base] + result
    n //= base
print(result)
```

Остаток `n % base` берём как индекс в строке `digits`. Каждую новую цифру дописываем слева.

## 5. Быстрый перевод: группы бит

Каждая шестнадцатеричная цифра — это ровно 4 бита, восьмеричная — 3 бита.

`1010 1111₂ = AF₁₆`, потому что `1010 = A`, `1111 = F`. Проверим:

```python
print(int("10101111", 2))
print(int("AF", 16))
```

> 💡 Для перевода из двоичной в 16-ричную разбей число на группы по 4 бита справа налево.

## Типичные ошибки

> ⚠️ `ValueError: invalid literal for int() with base 2: '102'` — в двоичной записи появилась цифра 2.

> ⚠️ Остатки выписаны сверху вниз — получилось число наоборот. Дописывай цифру **слева**.

> ⚠️ `IndexError: string index out of range` — основание больше длины строки `digits`.

## Итоги

- Значение числа — сумма цифр на веса разрядов (степени основания).
- В другую систему: делим с остатком и читаем остатки снизу вверх.
- `bin`, `hex`, `int(s, base)` проверяют ручной ответ.
- 16-ричная цифра — 4 бита, 8-ричная — 3 бита.
