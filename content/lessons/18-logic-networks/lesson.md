## 1. Логика в Python

Значения 0 и 1 можно считать ложью и истиной. Операции: `and` (И, ∧), `or` (ИЛИ, ∨), `not` (НЕ, ¬). Чтобы вывести 0 или 1, оборачиваем в `int(...)`.

**Импликация** `x → y` ложна только когда `x = 1`, а `y = 0`. В Python: `(not x) or y`. **Эквивалентность** `x ≡ y` истинна, когда значения равны: `x == y`.

```python
x = 1
y = 0
print(int((not x) or y))
print(int(x == y))
```

Что выведет программа?

<details>
<summary>Показать ответ</summary>

`0` и `0`. Импликация `1 → 0` ложна, и значения `x` и `y` различны.

</details>

## 2. Перебор всех наборов

Для двух переменных вложенные циклы пробегают все 4 набора:

```python
for x in range(2):
    for y in range(2):
        print(x, y, int((not x) or y))
```

Это таблица истинности для `x → y`.

## 3. Какому столбцу какая переменная (МЦКО 5)

> 🎯 МЦКО: показан кусок таблицы, где функция равна 1, но столбцы без подписей. Нужно понять порядок переменных.

Идея: пробуем все порядки переменных (**перестановки**) и оставляем тот, для которого функция равна 1 во всех показанных строках.

```python
import itertools
for order in itertools.permutations("xyz"):
    print(order)
```

Выведется 6 порядков. Чтобы взять значение переменной `x` из строки `row`, используй `int(row[order.index("x")])`: `index` даёт номер столбца, где стоит буква.

## 4. IP-адрес и маска (МЦКО 7)

IP-адрес — четыре числа от 0 до 255 (**октета**), каждое — 8 бит. **Маска** показывает, какие биты относятся к сети (единицы), а какие к узлу (нули).

**Адрес сети** = IP **и** маска, побитово. Операция `&` берёт 1 только там, где обе единицы.

```python
print(130 & 192)
print(bin(130), bin(192))
```

Выведется `128`. Для четырёх октетов это делаем по очереди:

```python
ip = input().split(".")
mask = input().split(".")
for i in range(4):
    print(int(ip[i]) & int(mask[i]))
```

> 💡 Число единиц в маске (**длина префикса**) легко посчитать: `bin(255).count("1")` равно 8.

## Типичные ошибки

> ⚠️ `ValueError: invalid literal for int() with base 10: '192.168'` — не разрезала адрес: нужен `split(".")`.

> ⚠️ Писала `x -> y` вместо `(not x) or y`: в Python нет значка импликации.

> ⚠️ `IndexError: tuple index out of range` — в строке таблицы меньше значений, чем переменных, или неверно прочитан ввод.

## Итоги

- Импликация: `(not x) or y`, эквивалентность: `x == y`.
- Вложенные циклы или `permutations` перебирают наборы и порядки переменных.
- Адрес сети — побитовое `&` IP и маски по октетам.
- Длина префикса маски — число единиц в её двоичной записи.
