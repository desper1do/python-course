**Цель урока.** После урока ты умеешь:

- сравнивать значения: `==  !=  <  >  <=  >=`;
- писать `if`, `else` и `elif`, не путая отступы;
- вручную прослеживать, какая ветка выполнится.

**Связь с МЦКО.** Прямых заданий нет. Ветвления нужны почти везде: от перебора до проверки условий в заданиях 2, 6 и 13.

## 1. Сравнение

Сравнение даёт `True` (истина) или `False` (ложь). Знак `==` проверяет равенство, а одиночный `=` кладёт значение в переменную.

```python
age = int(input())
print(age >= 18)
print(age == 18)
```

> ⚠️ `=` — «положить», `==` — «равно ли?». Путать их — самая частая ошибка.

## 2. if: сделать, если верно

После условия ставим двоеточие, а действие пишем **с отступом** (4 пробела). Всё, что с отступом, выполняется только когда условие истинно.

```python
age = int(input())
if age >= 18:
    print("Можно")
print("Конец")
```

Строка «Конец» без отступа, поэтому выводится всегда.

## 3. else: иначе

```python
age = int(input())
if age >= 18:
    print("Можно")
else:
    print("Нельзя")
```

Что выведет программа при `age = 18`? А при `17`?

<details>
<summary>Показать ответ</summary>

При 18 выведется `Можно` (знак `>=` включает 18), при 17 выведется `Нельзя`.

</details>

## 4. elif: несколько вариантов

Условия проверяются сверху вниз. Как только одно истинно, остальные пропускаются.

```python
score = int(input())
if score >= 85:
    print("Пять")
elif score >= 70:
    print("Четыре")
else:
    print("Меньше четырёх")
```

Трассировка при `score = 72`:

| шаг | проверка | результат | вывод |
|---|---|---|---|
| 1 | `72 >= 85` | `False` | |
| 2 | `72 >= 70` | `True` | `Четыре` |
| 3 | остальное | пропущено | |

> 💡 Порядок важен: начинай с самого строгого условия. Если поставить `score >= 70` первым, число 90 тоже попадёт в «Четыре».

## 5. Сравнение строк и накопление максимума

Строки сравниваются так же: `if password == "python":`. А наибольшее из чисел можно искать по шагам: взять первое, потом заменять, если нашлось больше.

```python
a = int(input())
b = int(input())
biggest = a
if b > biggest:
    biggest = b
print(biggest)
```

## Типичные ошибки

> ⚠️ `SyntaxError: expected ':'` — забыла двоеточие после условия.

> ⚠️ `IndentationError: expected an indented block after 'if' statement on line 2` — после `if` нет отступа.

> ⚠️ `SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?` — в условии написала `=` вместо `==`.

## Итоги

- Сравнения дают `True` или `False`; `==` проверяет равенство.
- После `if условие:` и `else:` ставится двоеточие, действия пишутся с отступом.
- `elif` проверяется, только если предыдущие условия ложны.
- Условия идут сверху вниз, порядок важен.
