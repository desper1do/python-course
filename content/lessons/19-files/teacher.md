# Урок 19. Числа из файла: пары соседних элементов

## Цели
- Читать последовательность чисел в список.
- Перебирать пары соседних `numbers[i]`, `numbers[i + 1]`.
- Решать задание типа 13: найти N, отобрать пары, вывести количество и максимум.

Связь с МЦКО: **задание 13**.

> **ВАЖНО — доработать позже.** Платформа пока не умеет файлы, поэтому числа подаются через stdin: первая строка — количество, затем числа по одному в строке. Когда появится поддержка файлов, задачи l19-t2…l19-t9 нужно переделать на чтение `13.txt` (`with open("13.txt")`, `read().split()`), добавить файлы данных в `data/` и генераторы в `_gen/`. Id задач при этом не менять.

## Как объяснять
- Устно за 5 минут: «В задании 13 всегда три этапа: прочитать числа, найти особое число N по правилу, пробежать по соседним парам и посчитать, сколько подошло и какая самая большая сумма. Меняется только правило. Поэтому делаем скелет программы и подставляем правило».
- Нарисовать числа в ряд и стрелками отметить пары.
- Каждую часть проверять отдельным `print` на маленьком примере.
- После решения — вывести два числа через пробел в правильном порядке.

## Типичные ошибки ученицы
- Цикл по парам до `len(numbers)`, а не до `len(numbers) - 1`.
- Ищет N среди всех чисел, забывает фильтр.
- Максимум начинает с 0, когда подходящих пар может не быть/суммы отрицательные (в наших задачах всё положительно).
- Путает «наименьшее» и «наибольшее» при поиске N.
- Перепутала порядок двух чисел в ответе.
