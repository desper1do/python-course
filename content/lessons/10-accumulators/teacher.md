## Как объяснять
- Накопитель — копилка: кладём по монете (сумма), считаем монеты (счётчик), запоминаем самую крупную (максимум).
- Для максимума: «рекордсмен» — выйти на старт с первым участником, дальше каждый новый сравнивается с рекордсменом.
- Для «соседних пар»: две ячейки, `prev` и `x`; после каждой проверки «сдвигаем» окно: `prev = x`.
- Простое число: «число с ровно двумя делителями». Обсудите, почему 1 — не простое.

## Типичные ошибки ученицы
- `biggest = 0` для отрицательных чисел.
- Накопитель внутри цикла.
- Забывает `prev = x`.
- Для задачи 8 пишет `x % k == 0` вместо `!=`.
- Читает на одно число больше или меньше (n и n - 1).
