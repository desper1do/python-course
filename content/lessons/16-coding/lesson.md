## 1. Равномерные и неравномерные коды

В **равномерном** коде у всех букв одинаковая длина (как в уроке 6). В **неравномерном** у частых букв коды короче, у редких длиннее. Это экономит память, но возникает вопрос: как понять, где кончается один код и начинается другой?

## 2. Условие Фано

**Условие Фано:** никакой код не является началом (**префиксом**) другого кода. Тогда сообщение однозначно разбирается слева направо.

- `A = 0`, `B = 10`, `C = 11` — условие выполнено;
- `A = 0`, `B = 01` — не выполнено: код `0` — начало кода `01`, и строка `01` можно прочесть двумя способами.

Проверка в Python: `a.startswith(b)` истинно, если строка `a` начинается с `b`.

```python
print("101".startswith("10"))
print("101".startswith("11"))
print("10".startswith("101"))
```

Что выведет программа?

<details>
<summary>Показать ответ</summary>

`True`, `False`, `False`. Длинная строка начинается с короткой, а не наоборот.

</details>

## 3. Декодирование и длина

Сообщение `ABAC` с кодами `A = 0`, `B = 10`, `C = 11` кодируется как `0 10 0 11`. Его длина `1 + 2 + 1 + 2 = 6` бит. Для декодирования идём по битам слева направо, накапливаем кусочек и, как только он совпал с кодом, записываем букву и начинаем заново.

```python
pieces = ["0", "10", "0", "11"]
total = 0
for piece in pieces:
    total += len(piece)
print(total)
```

## 4. Недостающие коды (МЦКО 1)

> 🎯 МЦКО: часть кодов известна, для остальных букв нужно выбрать коды, чтобы условие Фано выполнялось, а сообщение стало как можно короче. Самые частые буквы получают самые короткие свободные коды.

Пример: `A = 0` (10 раз), `B = 10` (5 раз), буквы `C` (3 раза) и `D` (2 раза) без кодов. Свободны только коды, начинающиеся с `11`: короче всего `110` и `111`. Длина: `10 + 10 + 9 + 6 = 35` бит.

Свободные коды удобно найти перебором: взять все строки из нулей и единиц до нужной длины и отсеять те, что начинаются с известного кода или являются его началом.

```python
codes = ["0", "10"]
for number in range(8):
    candidate = bin(number)[2:]
    ok = True
    for c in codes:
        if candidate.startswith(c) or c.startswith(candidate):
            ok = False
    print(candidate, ok)
```

## Типичные ошибки

> ⚠️ `AttributeError: 'int' object has no attribute 'startswith'` — метод применён к числу, а не к строке.

> ⚠️ Проверила только «короткий в начале длинного» и забыла обратное направление: нужны обе проверки.

> ⚠️ Забыла, что одинаковые коды у разных букв тоже нарушают условие.

## Итоги

- Условие Фано: ни один код не является началом другого.
- Длина сообщения: сумма длин кодов всех его букв.
- Недостающие коды ищем перебором строк из 0 и 1; частым буквам — короткие.
- `a.startswith(b)` проверяет, начинается ли `a` с `b`.
