## 1. Вложенные циклы

Внутренний цикл выполняется целиком на каждом шаге внешнего.

```python
for a in range(1, 4):
    for b in range(1, 3):
        print(a, b)
```

Выведется 6 пар: `1 1`, `1 2`, `2 1`, `2 2`, `3 1`, `3 2`.

## 2. itertools.product

Модуль `itertools` — второй разрешённый импорт. Функция `product(алфавит, repeat=k)` выдаёт все слова длины `k` в алфавитном порядке (если алфавит отсортирован). Каждое слово — набор букв, склеиваем его через `"".join`.

```python
import itertools
for letters in itertools.product("АБВ", repeat=2):
    print("".join(letters))
```

Что выведет программа первыми тремя словами?

<details>
<summary>Показать ответ</summary>

`АА`, `АБ`, `АВ`, затем `БА`, `ББ`, `БВ`, `ВА`, `ВБ`, `ВВ`. Всего 9 слов, как `3` в степени `2`.

</details>

## 3. Номер слова

`enumerate(слова, 1)` выдаёт пары «номер, слово», номера начинаются с 1.

```python
import itertools
for number, letters in enumerate(itertools.product("АБВ", repeat=2), 1):
    word = "".join(letters)
    if word == "БВ":
        print(number)
```

Выведется `6`. Ограничения («нет буквы Б», «нет двух В подряд») добавляются условием `if`: подходящие слова считаем, остальные пропускаем. Проверка «две подряд» — `"ВВ" in word`.

## 4. Автомат (МЦКО 2)

> 🎯 МЦКО: алгоритм над двоичной записью числа. Пример. `N` записывают в двоичной; если `N` чётное, справа дописывают `0`, иначе `11`; результат `R` — число в десятичной.

```python
n = 5
s = bin(n)[2:]
if n % 2 == 0:
    s += "0"
else:
    s += "11"
print(int(s, 2))
```

Для `N = 5`: `101` → `10111` → `R = 23`. «Найди наименьшее `N`, при котором `R` больше `X`» — перебираем `N = 1, 2, 3, ...`.

## 5. RSA (МЦКО 8)

> 🎯 МЦКО: даны простые `p` и `q`. Считаем `f = (p - 1) * (q - 1)`. Ищем `d`, для которого `(d * e) % f == 1`.

Перебираем `d` в нужном диапазоне и проверяем условие. Остаток `%` из урока 2.

## Типичные ошибки

> ⚠️ `ModuleNotFoundError: No module named 'itertool'` — опечатка в названии модуля. Правильно `itertools`.

> ⚠️ `TypeError: sequence item 0: expected str instance, int found` — в `"".join` попали числа, а не буквы.

> ⚠️ Нумерация идёт с 0, а нужна с 1: в `enumerate` добавь второй аргумент `1`.

## Итоги

- `enumerate(..., 1)` нумерует с единицы.
