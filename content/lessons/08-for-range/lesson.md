## 1. range(n)

Если число повторов известно заранее, удобнее `for`. Переменная `i` сама принимает значения из `range`.

```python
for i in range(4):
    print(i)
```

Что выведет программа? Подумай: считать начинаем с 0 или с 1? Заканчиваем на 4 или на 3?

<details>
<summary>Показать ответ</summary>

`0`, `1`, `2`, `3`. Счёт идёт с нуля, число 4 в диапазон не входит.

</details>

## 2. Три формы range

| запись | какие числа | пример |
|---|---|---|
| `range(b)` | от 0 до `b - 1` | `range(4)` даёт 0, 1, 2, 3 |
| `range(a, b)` | от `a` до `b - 1` | `range(2, 6)` даёт 2, 3, 4, 5 |
| `range(a, b, step)` | от `a` с шагом `step`, пока меньше `b` | `range(2, 10, 3)` даёт 2, 5, 8 |

> 💡 Последнее число (`b`) в диапазон **не входит**. Чтобы дойти до `n` включительно, пиши `range(1, n + 1)`.

```python
n = int(input())
for i in range(1, n + 1):
    print(i)
```

## 3. Отрицательный шаг

Шаг может быть отрицательным: тогда считаем вниз, и `b` тоже не входит.

```python
for i in range(5, 0, -1):
    print(i)
```

Выведется `5`, `4`, `3`, `2`, `1`.

## 4. Трассировка

Сумма чисел от 1 до 3:

```python
total = 0
for i in range(1, 4):
    total += i
print(total)
```

| итерация | `i` | `total` до | `total` после |
|---|---|---|---|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |

## 5. for или while

- `for` — когда число шагов или диапазон известны заранее;
- `while` — когда нужно «пока не случится что-то»: ввод до нуля, цифры числа.

Цикл можно вложить в `if` и наоборот:

```python
for i in range(1, 11):
    if i % 3 == 0:
        print(i)
```

## Типичные ошибки

> ⚠️ `TypeError: 'float' object cannot be interpreted as an integer` — в `range` передали дробное число. Для `/` используй `//`.

> ⚠️ `SyntaxError: expected ':'` — забыла двоеточие после `for i in range(...)`.

> ⚠️ Ответ на единицу меньше — написала `range(1, n)` вместо `range(1, n + 1)`.

## Итоги

- `for i in range(...)` перебирает числа по порядку.
- Последнее число в `range` не входит.
- Три формы: `range(b)`, `range(a, b)`, `range(a, b, step)`.
- `for` — число шагов известно, `while` — «пока условие».
