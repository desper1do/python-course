**Цель урока.** После урока ты умеешь:

- считать сумму и количество подходящих чисел;
- искать наибольшее и наименьшее;
- находить делители и проверять число на простоту.

> 🎯 МЦКО: задание 13 строится из этих шаблонов (минимум по условию, пары соседних, суммы). Простые числа и делители пригодятся в задании 8.

## 1. Сумматор и счётчик

Заводим переменную **до** цикла, меняем внутри. Если нужно считать только часть чисел, добавляем `if`.

```python
n = int(input())
total = 0
count = 0
for i in range(n):
    x = int(input())
    total += x
    if x > 0:
        count += 1
print(total, count)
```

## 2. Максимум и минимум

Начальное значение берём **из первого числа**, а потом сравниваем с каждым следующим.

```python
n = int(input())
biggest = int(input())
for i in range(n - 1):
    x = int(input())
    if x > biggest:
        biggest = x
print(biggest)
```

Трассировка для чисел `4, 9, 2`:

| шаг | `x` | `biggest` до | `x > biggest` | `biggest` после |
|---|---|---|---|---|
| начало | | | | 4 |
| 1 | 9 | 4 | True | 9 |
| 2 | 2 | 9 | False | 9 |

> ⚠️ Нельзя начинать с `biggest = 0`: если все числа отрицательные, ответ окажется неверным.

## 3. Делители

**Делитель** числа `n` — число, на которое `n` делится без остатка. Проверяем всех кандидатов от 1 до `n`.

```python
n = int(input())
for d in range(1, n + 1):
    if n % d == 0:
        print(d)
```

## 4. Простое число

Число **простое**, если у него ровно два делителя: 1 и оно само. Посчитаем делители.

```python
n = int(input())
count = 0
for d in range(1, n + 1):
    if n % d == 0:
        count += 1
if count == 2:
    print("Простое")
else:
    print("Составное")
```

Для `7` будет 2 делителя, для `1` — один, для `12` — шесть. Что выведет программа для `1`?

<details>
<summary>Показать ответ</summary>

`Составное`: у единицы один делитель, а не два. На самом деле единица не простая и не составная, поэтому в задачах мы условимся писать «Нет».

</details>

## 5. Заведомо большое число

Для минимума можно начать с числа, которое точно больше любого из данных, например `10**9`. Тогда первое же подходящее число станет новым минимумом.

```python
smallest = 10**9
```

## Типичные ошибки

> ⚠️ `NameError: name 'total' is not defined` — накопитель не создан до цикла.

> ⚠️ `ValueError: invalid literal for int() with base 10: ''` — читаешь больше чисел, чем есть во вводе.

> ⚠️ Ответ неверный, но ошибки нет: `total = 0` попал внутрь цикла и обнуляется на каждом шаге.

## Итоги

- Сумматор и счётчик создаём до цикла.
- Максимум: начать с первого числа (или очень малого), сравнивать с каждым.
- Минимум: начать с первого числа (или очень большого).
- Делители ищем перебором, простое число имеет ровно два делителя.
