**Цель урока.** После урока ты умеешь:

- объявлять функцию через `def` с параметрами и `return`;
- отличать `return` от `print`;
- писать функции-помощники и вызывать их в циклах.

**Связь с МЦКО.** Функции вроде `digit_sum` и `is_prime` пригодятся в заданиях 8, 11, 13: проверяем много чисел одной и той же проверкой.

## 1. Зачем функции

**Функция** — именованный кусок кода. Один раз пишем, много раз вызываем. Данные в функцию передают через **параметры**, а результат возвращает `return`.

```python
def square(x):
    return x * x

print(square(3))
print(square(10))
```

`def` объявляет функцию, `x` — параметр, `return` возвращает значение. Сама функция выполняется только когда её **вызывают**: `square(3)`.

## 2. return и print

`return` отдаёт значение туда, откуда функцию вызвали. `print` лишь выводит на экран. Что выведет программа?

```python
def double(x):
    return x * 2

def show(x):
    print(x * 2)

a = double(4)
b = show(4)
print(a)
print(b)
```

<details>
<summary>Показать ответ</summary>

Сначала `8` (это печатает сама `show`), затем `8` (печать `a`), затем `None`. Функция `show` ничего не вернула, поэтому в `b` оказалось `None`.

</details>

> ⚠️ Если в функции нет `return`, она возвращает `None`. Сразу после `return` функция заканчивается.

## 3. Функция с условием

```python
def is_even(n):
    return n % 2 == 0

print(is_even(10))
print(is_even(7))
```

Функция вернёт `True` или `False`, и её удобно ставить прямо в `if`: `if is_even(n):`.

## 4. Функция с циклом

```python
def digit_sum(n):
    total = 0
    while n > 0:
        total += n % 10
        n //= 10
    return total

print(digit_sum(482))
```

Выведется `14`. Переменные `total` и `n` существуют только внутри функции.

## 5. Ранний return

`return` можно поставить внутри цикла: как только нашли ответ, выходим.

```python
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, n):
        if n % d == 0:
            return False
    return True

for x in range(1, 11):
    if is_prime(x):
        print(x)
```

Выведется `2`, `3`, `5`, `7`.

> 💡 Сначала пиши функцию, потом ввод и вызов. Функции объявляются выше места, где их вызывают.

## Типичные ошибки

> ⚠️ `NameError: name 'square' is not defined` — вызываешь функцию выше её `def`, либо опечатка в имени.

> ⚠️ `TypeError: square() missing 1 required positional argument: 'x'` — вызвала `square()` без числа в скобках.

> ⚠️ В `print` пришло `None` — в функции забыла `return`.

## Итоги

- `def имя(параметры):` объявляет функцию, тело с отступом.
- `return` возвращает результат и завершает функцию.
- Функции-помощники делают программу короче и понятнее.
- Вызывай функцию в цикле, чтобы проверить много чисел.
