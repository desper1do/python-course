**Цель урока.** После урока ты умеешь:

- писать цикл `while` и прослеживать его по таблице;
- останавливать бесконечный цикл;
- разбирать число по цифрам в цикле.

**Связь с МЦКО.** Циклы нужны для заданий 2, 6, 8, 11, 13: везде что-то перебираем или считаем в цикле.

## 1. Что такое цикл

**Цикл** повторяет блок команд. Одно выполнение блока называется **итерацией**. Цикл `while` работает, пока условие истинно. Условие проверяется перед каждой итерацией.

```python
i = 1
while i <= 3:
    print(i)
    i = i + 1
print("Конец")
```

Что выведет программа? Заполни таблицу сама, потом проверь.

| итерация | `i` до | условие `i <= 3` | вывод | `i` после |
|---|---|---|---|---|
| 1 | 1 | True | 1 | 2 |
| 2 | 2 | True | 2 | 3 |
| 3 | 3 | True | 3 | 4 |
| 4 | 4 | False | | |

<details>
<summary>Показать ответ</summary>

Выведется `1`, `2`, `3` и `Конец`. На четвёртой проверке условие ложно, цикл заканчивается.

</details>

Переменная `i`, которая считает шаги, называется **счётчиком**.

## 2. Бесконечный цикл

Если забыть изменить `i`, условие никогда не станет ложным. Программа зависнет. Нажми кнопку «■ Стоп» (или `Ctrl+C` в терминале).

```python
i = 1
while i <= 3:
    print(i)
```

> ⚠️ Бесконечный цикл: счётчик не меняется. Перед запуском спрашивай себя, что в цикле меняется и когда условие станет ложным.

## 3. Сокращённая запись и сумматор

`i += 1` значит `i = i + 1`. Переменная, в которую накапливаем результат, называется **сумматором**.

```python
n = int(input())
i = 1
total = 0
while i <= n:
    total += i
    i += 1
print(total)
```

## 4. Цифры числа в цикле

Последняя цифра — `n % 10`, число без неё — `n // 10`. Повторяем, пока число не станет 0. Запись `n //= 10` значит `n = n // 10`.

```python
n = int(input())
while n > 0:
    print(n % 10)
    n //= 10
```

Для `n = 482` выведется `2`, `8`, `4`: цифры с конца.

## 5. Читаем, пока не 0

Иногда число повторов заранее неизвестно. Тогда условие завязано на ввод.

```python
x = int(input())
while x != 0:
    print(x * 2)
    x = int(input())
```

## Типичные ошибки

> ⚠️ Программа не заканчивается — забыла `i += 1` внутри цикла. Нажми «■ Стоп».

> ⚠️ `NameError: name 'total' is not defined` — переменная `total` не была создана до цикла. Создай `total = 0` заранее.

> ⚠️ `IndentationError: expected an indented block after 'while' statement on line 3` — у тела цикла нет отступа.

## Итоги

- `while условие:` повторяет блок, пока условие истинно.
- В цикле должно что-то меняться, иначе цикл бесконечный.
- Сумматор создаём до цикла, обновляем внутри.
- Цифры числа: `n % 10` и `n //= 10`, пока `n > 0`.
