# Формат контента: что поддерживает платформа

Шпаргалка для авторов уроков. Пополняется по мере появления новых возможностей.
Полная спецификация — PROMPT.md, раздел 7. Контент читается с диска на каждый запрос, пересборка не нужна.

## Базовый формат (работает сейчас)

```
content/curriculum.yaml                 # blocks + lessons (порядок прохождения)
content/lessons/<id>/lesson.md          # front matter (title, subtitle, goal) + GFM Markdown
content/lessons/<id>/tasks.yaml         # список задач
content/lessons/<id>/teacher.md         # для преподавателя, ученице не показывается
```

**lesson.md:**
- GFM: заголовки, списки, таблицы, `inline code`.
- ` ```python ` — блок с подсветкой и кнопками «▶ В редактор» / «Копировать».
- ` ```text ` — блок «Вывод» (пунктирная рамка).
- Врезки — цитата, начинающаяся с эмодзи:
  `> 💡 …` / `> 🎯 …` / `> 📌 …` / `> 🤔 …` — акцентная;
  `> ⚠️ …` / `> ❗ …` — жёлтая (предупреждение);
  `> ✅ …` — зелёная; прочие цитаты — нейтральные.
- Сворачиваемый ответ:
  ```html
  <details>
  <summary>Показать ответ</summary>

  Текст ответа (Markdown работает, нужна пустая строка после summary).
  </details>
  ```
- Директивы `:::` и формулы `$…$` пока НЕ поддерживаются.

**tasks.yaml** (только `type: code`): `id, type, title, level, required, statement,
input_format, output_format, starter, examples, tests (hidden: true), checker (exact | tokens), hints,
solution, explanation`. Неизвестные ключи игнорируются. `solution` и `explanation` ученице не отдаются.

## Этап 1 (платформа)

Нового синтаксиса для авторов нет. Изменения в интерфейсе:
- статус урока «Пройден» — только если решены все `required`-задачи или стоит ручная отметка
  (её теперь можно снять кнопкой в конце теории);
- название платформы — «Курс по Python».

## Видимость тестов (вкладка «Тесты»)

Скрытые тесты (`hidden: true`) до «Проверить» наружу не отдаются (в условии видны только `examples`); после проверки
по умолчанию раскрываются полностью — и пройденные, и упавшие (`HIDDEN_TESTS_REVEAL=always|failed|never` в `backend/app/config.py`
или переменной окружения). Поэтому в скрытых тестах не должно быть ничего, что жалко показать ученице.
