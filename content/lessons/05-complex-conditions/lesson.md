**Связь с МЦКО.** Это мост к заданию 5 (логические функции и таблицы истинности): там нужно так же вычислять сложные выражения для разных значений.

## 1. and, or, not

- `A and B` истинно, только если истинны **обе** части;
- `A or B` истинно, если истинна **хотя бы одна**;
- `not A` переворачивает: из `True` делает `False`.

| A | B | A and B | A or B |
|---|---|---|---|
| False | False | False | False |
| False | True | False | True |
| True | False | False | True |
| True | True | True | True |

```python
n = int(input())
if n >= 10 and n <= 99:
    print("Двузначное")
else:
    print("Нет")
```

Заметь: в каждой части пишем полное сравнение. `n >= 10 and <= 99` — ошибка.

## 2. Приоритет

Сначала выполняется `not`, потом `and`, потом `or`. Скобки главнее. Что выведет программа?

```python
print(True or False and False)
print((True or False) and False)
```

<details>
<summary>Показать ответ</summary>

`True`, затем `False`. В первой строке сначала считается `False and False`, получается `False`, а потом `True or False` даёт `True`. Во второй скобки меняют порядок.

</details>

## 3. Разбор вручную

Вычислим `not (a > b) or (c == 0 and a > 0)` для `a = 2, b = 5, c = 0`:

| шаг | выражение | значение |
|---|---|---|
| 1 | `a > b` → `2 > 5` | `False` |
| 2 | `not False` | `True` |
| 3 | `c == 0 and a > 0` | `True and True` → `True` |
| 4 | `True or True` | `True` |

Так же строится таблица: берём каждый набор значений и считаем по шагам.

## 4. Вложенные if

Внутрь ветки можно вложить ещё один `if`. Отступ каждого уровня — 4 пробела.

```python
x = int(input())
y = int(input())
if x > 0:
    if y > 0:
        print("Первая четверть")
    else:
        print("Четвёртая четверть")
else:
    print("Левая половина")
```

> 💡 Вложенный `if` часто заменяется одним сложным: `if x > 0 and y > 0`. Выбирай то, что понятнее.

## Типичные ошибки

> ⚠️ `SyntaxError: invalid syntax` в строке `if n >= 10 and <= 99:` — после `and` нужно полное сравнение: `n <= 99`.

> ⚠️ Условие `if a == 1 or 2:` не вызывает ошибки, но всегда истинно: `2` само считается «правдой». Пиши `a == 1 or a == 2`.

> ⚠️ `IndentationError: unindent does not match any outer indentation level` — у вложенных строк не совпали отступы.

## Итоги

- `and` — обе части истинны, `or` — хотя бы одна, `not` — переворот.
- Приоритет: `not`, `and`, `or`; скобки главнее.
- В каждой части условия пишем полное сравнение.
- Вложенный `if` — это «если, и внутри ещё если».
