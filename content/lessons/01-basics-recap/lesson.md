**Цель урока.** После урока ты умеешь:

- выводить текст и числа командой `print`;
- хранить значения в переменных;
- читать данные через `input()` и превращать их в числа через `int(input())`.

**Связь с МЦКО.** Прямых заданий пока нет. Это основа: все задачи МЦКО мы будем решать программами, которые читают данные и считают.

## 1. print: вывести на экран

`print` показывает на экране то, что в скобках. Текст (строка) пишем в кавычках, числа без кавычек. Если перечислить значения через запятую, они выведутся в одной строке через пробел.

```python
print("Привет!")
print(2 + 3)
print("Мне", 15, "лет")
```

> 💡 Каждый `print` начинает новую строку.

## 2. Переменные

**Переменная** — это имя, под которым хранится значение. Знак `=` значит «положить в переменную», а не «равно».

Что выведет эта программа? Подумай, потом открой ответ.

```python
age = 15
print(age)
age = age + 1
print(age)
```

<details>
<summary>Показать ответ</summary>

Сначала `15`, потом `16`: справа считается новое значение, и оно кладётся обратно в `age`.

</details>

Переменная может хранить и текст:

```python
name = "Аня"
print("Привет,", name)
```

## 3. input: ввести с клавиатуры

`input()` останавливает программу и ждёт, пока ты напечатаешь строку и нажмёшь Enter. То, что ты напечатала, попадает в переменную.

```python
name = input()
print("Привет,", name)
```

> 💡 Запусти и впиши своё имя в консоль. Это тот же код, но имя теперь вводит человек.

## 4. Типы: str, int, float

У каждого значения есть **тип**:

| тип | пример | что это |
|---|---|---|
| `int` | `15` | целое число |
| `float` | `3.5` | дробное число (через точку, не через запятую) |
| `str` | `"15"` | строка, то есть текст |

Главное: **`input()` всегда возвращает строку**, даже если ты ввела цифры. Что выведет программа, если ввести `5` и `3`?

```python
a = input()
b = input()
print(a + b)
```

<details>
<summary>Показать ответ</summary>

`53`. Для строк `+` склеивает текст, а не складывает числа.

</details>

Чтобы получить число, оборачиваем `input()` в `int()`:

```python
a = int(input())
b = int(input())
print(a + b)
```

Теперь на вводе `5` и `3` получится `8`.

## Типичные ошибки

> ⚠️ `ValueError: invalid literal for int() with base 10: 'abc'` — в `int(input())` ввели не целое число (буквы, `3.5`, пробел). Вводи только целое число.

> ⚠️ `NameError: name 'Привет' is not defined` — забыла кавычки вокруг текста или опечаталась в имени переменной. Текст пишем в кавычках.

> ⚠️ `TypeError: unsupported operand type(s) for +: 'int' and 'str'` — сложила число со строкой. Преврати строку в число через `int(...)`.

## Итоги

- `print(...)` выводит значения, через запятую они идут в одной строке.
- Переменная хранит значение, `=` кладёт его внутрь.
- `input()` возвращает строку.
- `int(input())` даёт целое число, с ним можно считать.
