## 1. Дробные числа

Справа от точки веса разрядов — это `1/2, 1/4, 1/8, ...` (степени двойки со знаком минус).

`0.101₂ = 1/2 + 0/4 + 1/8 = 0.625`.

Из десятичной дроби в двоичную: умножаем дробную часть на 2, целую часть берём как очередную цифру.

`0.625 * 2 = 1.25` → 1; `0.25 * 2 = 0.5` → 0; `0.5 * 2 = 1.0` → 1. Получилось `0.101₂`.

Чтобы не было ошибок округления, дробь `p/q` храним двумя целыми числами:

```python
p = 5
q = 8
bits = ""
while p != 0:
    p *= 2
    if p >= q:
        bits += "1"
        p -= q
    else:
        bits += "0"
print(bits)
```

Выведется `101`: это дробь `5/8 = 0.625`.

## 2. Арифметика в разных системах

Правило: переводим в десятичную, считаем, переводим обратно. Прибавим `1011₂` и `17₈`:

```python
a = int("1011", 2)
b = int("17", 8)
print(a + b)
print(bin(a + b)[2:])
```

Что выведет программа?

<details>
<summary>Показать ответ</summary>

`26` и `11010`: `11 + 15 = 26`, а `26` в двоичной это `11010`.

</details>

## 3. Неизвестная цифра в основании 12

В системе по основанию 12 цифры `0–9`, затем `A = 10` и `B = 11`. Если одна цифра неизвестна (`x`), пробуем все возможные.

```python
digits = "0123456789AB"
s = "3x5"
for d in digits:
    value = int(s.replace("x", d), 12)
    if value % 13 == 0:
        print(d, value // 13)
```

Метод `replace(старое, новое)` заменяет часть строки. Здесь для `x = 6` получаем `365₁₂ = 3*144 + 6*12 + 5 = 509`, не кратно 13, а для подходящей цифры программа выведет её и частное.

## 4. Дополнительный код (8 бит)

Так в компьютере записывают отрицательные числа. Для `-n`:

1. запиши `n` в двоичной в 8 бит;
2. инвертируй все биты (0 ↔ 1);
3. прибавь 1.

`-5`: `00000101` → `11111010` → `11111011`.

Быстрее: код числа `-n` — это двоичная запись числа `256 - n`.

```python
n = 5
print(bin(256 - n)[2:])
```

Обратно: если код начинается с `1`, число отрицательное и равно `код - 256`.

## Типичные ошибки

> ⚠️ `ValueError: invalid literal for int() with base 12: '3x5'` — забыла заменить `x` на цифру.

> ⚠️ Забыла, что `A` и `B` в двенадцатеричной — это 10 и 11, а не буквы-«неизвестные».

> ⚠️ Забыла дополнить код нулями до 8 бит: `101` вместо `00000101`.
